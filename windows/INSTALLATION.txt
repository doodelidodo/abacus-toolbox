Abacus Toolbox  |  Installation als Windows-Dienst
=================================================

Voraussetzung: Windows Server / Windows 10+, Administratorrechte. Python ist NICHT nötig.

1. ZIP auf den Server kopieren und entpacken, z.B. nach C:\Install\abacus-toolbox

2. Optional: prüfen, ob Port 8000 frei ist (keine Ausgabe = frei):

     Get-NetTCPConnection -LocalPort 8000 -State Listen -ErrorAction SilentlyContinue

   Das Installations-Script prüft das ebenfalls und bricht bei belegtem Port ab, ohne etwas zu ändern.

3. PowerShell als Administrator öffnen:

     cd C:\Install\abacus-toolbox
     powershell -ExecutionPolicy Bypass -File .\install-service.ps1

   Am Ende muss "Health: ok" stehen.

   Optionen:
     -Port 8001                       anderer Port (Standard 8000)
     -ApiKey "langer-geheimer-key"    API-Key verlangen (Header X-API-Key)
     -ListenAll                       auch von anderen Rechnern erreichbar (nur mit -ApiKey!)
     -Modules "fsm_xlsx"              nur diese Werkzeuge aktivieren (Standard: alle)

4. In Abacus (Baustein "Webservice Aufruf ausführen"), Beispiel FSM XML -> Excel:
     Method       POST
     URI          http://localhost:8000/fsm/xml-to-xlsx
     Headers      Content-Type: application/xml   (+ X-API-Key: ..., falls gesetzt)
     QueryParams  filename=<Name der XML-Datei>
     BodyFile     die XML-Datei
     -> Die Excel-Datei steht in ResponseFile.

Danach:
  Programmordner   C:\Program Files\AbacusToolbox
  Einstellungen    settings.json            (nach Änderung: Restart-Service AbacusToolbox)
  Feldkonfig       xml_to_xlsx_config.json  (wirkt sofort)
  Logs             logs\service.log
  Test             http://localhost:8000/health  ·  Werkzeuge: /modules  ·  Swagger: /docs
  Update           neue ZIP entpacken, install-service.ps1 erneut ausführen
                   (Einstellungen und Feldkonfig bleiben erhalten)
  Entfernen        powershell -ExecutionPolicy Bypass -File .\uninstall-service.ps1 [-RemoveFiles]
